# Zhamlik 2.0 - Современная финансовая система

Полный редизайн проекта Zhamlik на современном стеке технологий с премиум UI/UX.

## 🚀 Технологический стек

- **Next.js 15** - React фреймворк с App Router
- **TypeScript** - Типизация
- **Tailwind CSS v4** - Мощный CSS framework с JIT-компиляцией
- **shadcn/ui** - Красивые и доступные компоненты
- **Framer Motion** - Плавные анимации
- **Lucide React** - Современные иконки

## ✨ Возможности

### 🎨 Премиум дизайн
- **Glassmorphism** - Стеклянный эффект с backdrop-blur
- **Gradient Accents** - Градиентные акценты для глубины
- **Smooth Animations** - Плавные анимации с Framer Motion
- **Dark Mode** - Тёмная тема из коробки
- **Responsive** - Адаптивный дизайн для всех устройств

### 📱 Навигация
- **Desktop Sidebar** - Боковая панель для десктопа
- **Mobile Menu** - Адаптивное меню для мобильных
- **Active States** - Анимированные активные состояния
- **Smooth Transitions** - Плавные переходы

### 📊 Дашборд
- **Stats Cards** - Карточки со статистикой и трендами
- **Recent Transactions** - Последние транзакции
- **Animations** - Каскадные анимации появления

## 🛠️ Установка и запуск

### Требования
- Node.js 18+
- npm или yarn или pnpm

### Установка зависимостей
```bash
npm install
```

### Запуск дев сервера
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшна
```bash
npm run build
npm start
```
